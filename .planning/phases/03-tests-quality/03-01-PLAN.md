Create `tests/test_voice.py` with the following tests. All tests use the `client` and `session` fixtures from conftest.py. The LLM Agent must be mocked to avoid real API calls.

**Shared mock setup (use as a helper or inline in each test):**
Mock `app.brand.api.servicer.Agent` so that `Agent(model, output_type).run_sync(prompt)` returns a MagicMock whose `.output` attribute is a `VoiceProfileLLMResult` with these values:
- warmth=0.7, seriousness=0.3, technicality=0.5, formality=0.4, playfulness=0.6
- target_demographic="Tech-savvy professionals aged 25-40"
- style_guide=["Be concise", "Use active voice", "Avoid jargon"]
- writing_example="Our platform empowers you to build faster."

**Shared brand creation helper:**
POST to `public/api/brands` with `{"url": "https://example.com", "docs": ["https://example.com/about"]}`, assert 200, return the brand id from response JSON.

**Test 1: `test_generate_voice_profile_happy_path`** (per TEST-01, TEST-02)
1. Create a brand via helper.
2. With Agent mocked, POST to `public/api/brands/{brand_id}/voices:generate` with `{"writing_samples": ["We build great software.", "Our team is passionate."], "llm_model": "gpt-4o"}`.
3. Assert response status == 200.
4. Assert response JSON contains all required fields: `id`, `brand_id`, `version`, `warmth`, `seriousness`, `technicality`, `formality`, `playfulness`, `target_demographic`, `style_guide`, `writing_example`, `llm_model`, `created_at`.
5. Assert `version == 1` (per TEST-02).
6. Assert `brand_id` matches the created brand's id.
7. Assert `llm_model == "gpt-4o"`.
8. Assert each float field (warmth, seriousness, technicality, formality, playfulness) is a float and `0.0 <= value <= 1.0`.
9. Assert `style_guide` is a list and each element is a str.
10. Assert `target_demographic` is a str.
11. Assert `writing_example` is a str.
12. Assert `id` is a valid UUID string.
13. Assert `created_at` is a non-empty string.
14. Cleanup: fetch VoiceProfile from session by id, delete it, then delete the brand, commit.

**Test 2: `test_generate_voice_404_unknown_brand`** (validates 404 path)
1. POST to `public/api/brands/00000000-0000-0000-0000-000000000000/voices:generate` with valid body `{"writing_samples": ["sample"], "llm_model": "gpt-4o"}`.
2. Assert response status == 404.
3. No cleanup needed.

**Test 3: `test_generate_voice_422_missing_writing_samples`** (validates 422 path)
1. Create a brand via helper.
2. POST to `public/api/brands/{brand_id}/voices:generate` with body `{"llm_model": "gpt-4o"}` (missing writing_samples).
3. Assert response status == 422.
4. Cleanup: delete the brand, commit.

**Type annotations:** All test functions must have return type `-> None`. Use `from unittest.mock import patch, MagicMock`. Import `VoiceProfileLLMResult` from `app.brand.api.schemas`. Import `Brand, VoiceProfile` from `app.brand.db.models`.

**Style:** Follow the exact pattern from test_brand.py -- no classes, plain functions with `client: TestClient, session: Session` parameters, type annotations on all params.
